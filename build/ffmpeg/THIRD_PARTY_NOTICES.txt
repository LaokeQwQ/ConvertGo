ConvertGo bundled FFmpeg third-party notices
============================================

ConvertGo executes FFmpeg and ffprobe as separate local programs. These
notices describe those programs and their bundled dependencies. They do
not assign a license to the ConvertGo application itself.

The bundled FFmpeg build enables GPL components, including libx264 and
libx265, and is distributed with corresponding source. It is not a
nonfree FFmpeg build. FFmpeg is provided without warranty to the extent
permitted by the applicable licenses. The complete upstream license texts,
copyright notices and authorship files are included under licenses/;
the exact corresponding source archives are under sources/. Preserve
those materials when redistributing this bundle.

The source lockfile and build-info.json identify the exact source version,
URL and SHA-256 for every library actually used by the current target:

Windows builds use the source-pinned LLVM-MinGW toolchain. Runtime license
files from that exact toolchain are included under licenses/llvm-mingw/.
Corresponding LLVM 20.1.8 libc++/libc++abi/libunwind/compiler-rt sources,
the exact MinGW-w64 source commit and matching toolchain build scripts are
also included. LLVM components use Apache-2.0 with the LLVM exception;
MinGW-w64 contains multiple permissive licenses, preserved in its source
and copied notices. The Microsoft UCRT is supplied by Windows itself.
macOS system frameworks and Linux system libraries/fonts are platform
requirements, not redistributed proprietary encoder SDKs.

To rebuild or modify the bundled programs, read BUILDING.txt and the
build-recipe/ directory. The distributed metadata contains every FFmpeg
configure argument and external-library build command. No private keys or
generated binaries are committed to the source repository. The release
workflow verifies upstream archives before building and ships those same
archives beside the binaries.
